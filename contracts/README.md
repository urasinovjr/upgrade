# Контракты UpGrade

`openapi-0.2.0.json` генерируется из FastAPI во внутреннем тестовом режиме.
`postman-0.2.0.json` содержит соответствующие маршруты и шаблоны запросов.

Пересоздание из корня:

```sh
cd backend
uv run python -m app.contracts
```

В Postman задайте `baseUrl`, `origin`, переменные тел и параметров маршрута.
После входа используйте cookie сессии и её `csrfToken`. Репетитор и ученик
проверяются в отдельных сессиях. Шаблон сдачи без файлов содержит пустой
`taskFiles`; для фотографий добавьте поле файла с UUID и тот же UUID в массив
соответствующего задания. `meta.id` сохраняйте при повторе того же запроса.

Права: репетитор видит своё ДЗ, сдачи, черновики, материалы и события. Ученик
использует `/api/student`, получает собственные назначения и опубликованные
результаты. Доступ к чужому ID и файлу отклоняется. Неактивная подписка даёт
просмотр; новые сдачи, назначения и изменения блокируются. Учёт времени
доступен только включённым в пилот репетиторам.

Ожидаемые ошибки: 401 без сессии, 403 при неверной роли/CSRF/origin, 402 при
окончании доступа на запись, 404 при недоступном объекте, 409 при конфликте
ревизии, неподтверждённых условиях, замороженном ДЗ или незавершённой предыдущей
сдаче, 413 при превышении размера, 415 при неподдерживаемом файле, 422 при
невалидном теле. Тело содержит `detail` с кодом; некоторые ошибки содержат
`revision`, `pages`, `places` или `blockers`. Актуальный каталог кодов:
`backend/app/errors.py`.

Состояния ДЗ: черновик, назначено (условия зафиксированы). Сдачи:
`preparation`, `queued`, `processing`, `ready`, `needs_input`, `failed`,
`confirmed`. Это технические состояния. Итог задания хранится отдельно:
`solved`, `errors`, `needs_clarification`. Ученик не получает технические
черновики, исходные ответы провайдера и гипотезы.

Эта коллекция не является отчётом о прогонах Postman. Контракт и права проверяет
pytest; функциональный сценарий UI проверяет Playwright. Реальный ИИ,
экспертная разметка и пользовательская приёмка требуют отдельных протоколов.
